How it works

This solver uses Herbert Kociemba's two-phase algorithm to find solutions in 20 moves or fewer. The cube state is represented as a 54-character facelet string — nine stickers per face, ordered U, R, F, D, L, B.

Type moves directly (U, U', D, D', L, L', R, R', F, F', B, B') or use the controls above. The 3D cube responds to mouse drag for camera rotation.
